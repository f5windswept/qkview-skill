# QKView Skill

Automate the creation of a BIG-IP utilization report using qkview graphs in iHealth.

## Requirements
- MacOS local CLI
- iHealth session extraction from Chrome or Firefox cookies on macOS
- email address of the uploader to ihealth
- Notion

## Getting Started
Log into ihealth
export NOTION_API_KEY

## Prompt
Use ~/code/qkview-skill to generate and publish a qkview report for customer@example.com to this Notion page: https://www.notion.so/example/example-page-asdfasdf
